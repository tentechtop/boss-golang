# AI 求职 Copilot

本项目是一个本地运行的求职辅助系统，后端全部使用 Go 标准库实现。

## 功能

- 多选本地项目目录并扫描技术栈、模块和证据文件。
- 生成基础 Markdown / HTML 简历。
- 分析岗位 JD，输出匹配度、关键词、缺口和风险。
- 根据岗位生成定制简历。
- 生成 BOSS 沟通草稿，由用户确认后发送。
- 持续自动模式会根据岗位信息和有效简历生成首条消息，并主动联系 HR。
- 在 BOSS 搜索结果页扫描当前可见岗位，标记高匹配岗位并加入投递队列。
- 从投递队列一键准备岗位定制简历和开场白，用户确认后进入沟通。
- 提供沙箱自动聊天 Demo，用于展示对话引擎能力。
- 记录投递反馈，形成后续优化数据。

## 启动

```powershell
go run ./cmd/server
```

打开：

```text
http://127.0.0.1:8083
```

如果 8083 已被占用，可以换一个空闲端口：

```powershell
$env:APP_ADDR="127.0.0.1:8090"
go run ./cmd/server
```

注意：Chrome 插件默认会打开 `http://127.0.0.1:8083/` 作为系统页。改端口后，本地后端接口仍会被插件探测，但系统页桥接建议继续使用 8083。

## 回复模型配置

用户可以在系统页“HR 自动回复”中明确选择本地 Codex、DeepSeek 或智谱 GLM。选择 DeepSeek 或智谱时需要填写对应 API Key；智谱默认使用免费的 `glm-4.7-flash`。主动联系 HR 前必须存在有效简历；模型不可用时，本地规则只引用岗位信息和简历中已填写的求职方向、城市、技能等真实内容。API Key 保存在本机数据目录中，接口不会回显明文。

也可以通过环境变量配置模型：

```powershell
$env:DEEPSEEK_API_KEY="你的 Key"
$env:ZHIPU_API_KEY="你的 Key"
go run ./cmd/server
```

## Chrome 插件

1. 打开 Chrome 扩展程序页面。
2. 启用开发者模式。
3. 加载 `extension` 目录。
4. 打开 BOSS 页面后点击插件读取岗位并生成草稿。

手动模式只填入草稿，不自动点击发送；持续自动模式开启后会主动发送首条沟通并继续处理 HR 新消息。
